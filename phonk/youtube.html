Search YouTube

Search results are filtered to videos YouTube marks as embeddable. Add a YouTube Data API key to search, then play results here on GameShelf.

Create a key in Google Cloud Console and enable YouTube Data API v3. The key is used only for searches in this page and is not saved. Restrict it to this API and your site’s HTTP referrer (for example, https://coolcat235.github.io/*); browser keys are visible to site visitors.

Only videos marked embeddable by YouTube are searched. Six results load at a time; press “Load more videos” for the next batch. YouTube may still limit playback by age, region, or other restrictions.
